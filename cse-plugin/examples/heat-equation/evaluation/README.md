# CSE behavioral evaluation

This package evaluates whether the installed private CSE plugin
is useful for this repository's intended scientific work. It does not evaluate
public-release readiness.

- [cases.yaml](cases.yaml) contains copyable, mutation-free prompts for all ten
  public entrypoints and representative internal handoffs.
- [rubric.md](rubric.md) defines the science-first behavioral criteria.
- [results.md](results.md) records concise sanitized observations and the
  evidence used for each conclusion.

Private task transcripts are never committed. Results name the prompt ID,
observed behavior, and repository evidence only.
