# Scientific decision records

Accepted records use one sequence: `0001-short-title.md`,
`0002-short-title.md`, and so on. Create one only when reversal is costly, code
and equations do not preserve the reason, genuine alternatives existed, and
the choice materially affects scientific or computational work. Superseded
records remain here, identify their replacement, and never release a number
for reuse.

Choose the focused starter under `templates/`; the repository's scientific
owner accepts the decision and evidence.
