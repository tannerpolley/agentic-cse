# Heat-equation scientific records

This tree owns the example's shared context, formulation, numerical methods,
verification evidence, decision-record sequence, writing rules, bibliography,
and tutorial manuscript. The populated root
`analyses/heat_verification/` set owns retained calculation values, scripts,
figures, and its reviewed notebook. `src/heat_verification/` owns reusable model
and method code.

- `CONTEXT.md` maps the question, terminology, and repository paths.
- `formulation.tex`, `methods.tex`, and `evidence.tex` define and assess the
  single-mode verification case.
- `adr/` is reserved for consequential scientific or computational decisions.
- `latex/` owns the shared bibliography and tutorial manuscript.
- `writing/` owns the example's style and deterministic writing rules.
