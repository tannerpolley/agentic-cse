# Scientific writing style

The installed CSE `scientific-writing` reference owns plugin-wide prose,
fidelity, and legitimate-academic-usage rules. Add only evidence-backed
project or venue style choices here; do not copy the shared rule lists.

Keep project-wide choices separate from named manuscript/deck sections. Follow
the installed `scientific-writing#standing-editorial-decisions` reference.
Each document section identifies its repository-relative main source,
supplement, and associated figure paths, with a decision table using columns
`Scope | Standing owner decision | Authority`. If an established brief owns
those decisions, the section holds only its pointer. With no standing owner
directions, state that none have been recorded; do not invent defaults.
