# CSE project guidance

This is a CSE project. Every agent performing scientific or engineering work
MUST use the installed CSE skills and MUST read `docs/scientific/README.md` and
`docs/scientific/CONTEXT.md` before selecting the evidence-justified CSE route.

CSE execution mode: direct.

Use native host delegation for bounded independent work when useful. The
current task remains accountable for the result.

This is a private computational research project, not a public package. Before
the first scientific write, state the question, intended use, starting CSE
stage, governing authority, required evidence, and supported claim boundary.
An unexplained numerical result enters Diagnose before implementation changes.

Use Explore for disposable calculations and Promote for durable methods,
results, records, or tests. Tests exist only for a numerical tolerance,
invariant, reference case, or one exact demonstrated failure.
Create an analysis research notebook only after useful numerical results exist,
then review the notebook and selected render together. Review advises; only the
investigator may promote the reviewed notebook for manuscript use.

Repository-specific scientific decisions live under `docs/scientific/` and
bounded retained calculations live under root `analyses/<short-id>/`.
