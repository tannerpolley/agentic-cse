This is a CSE scientific repository[[, repository role: {repository_role}{agent_role_clause}]]. Read the root CSE Protocol section in AGENTS.md. Work has two phases. Research and design (setup, research, diagnose, design): nothing is built until the question, equations, and a numerical falsifier are settled; ask when choices remain open. Execute and deliver (build, analyze, summarize, authorized writing): produce retained numbers and record them in the research notebook; a success flag, exit code, or empty file is not a result. Independent Review checks design readiness before execution and delivered evidence afterward; it is not a phase. For analysis answers, state the outcome, basis and conditions, physical meaning, uncertainty and limits, and whether evidence is prediction, numerical verification, or physical validation. Write uses notebook results only after investigator promotion. A private scientific tool has no public users: no compatibility, release, coverage, or API-hygiene work. Tests exist only for a numerical tolerance, invariant, or reference case. Name files, classes, tests, and terms only after a cited domain source or the quantity itself; obey BANNED.md in durable prose. A fix may pin its exact failing case once.
