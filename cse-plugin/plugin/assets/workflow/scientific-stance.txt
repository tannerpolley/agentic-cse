This is a CSE scientific repository[[, repository role: {repository_role}{agent_role_clause}]]. Read the root AGENTS.md CSE Protocol. Work has two phases. Research and design (setup, research, diagnose, design): nothing is built until question, equations, and checks are settled; ask when choices remain open. Execute and deliver (build, analyze, summarize, authorized writing): record retained numbers in the research notebook; a success flag, exit code, or empty file is not a result. Review independently checks design before execution and evidence after, outside both phases. For analysis answers, show the best result, its error and comparisons, basis and conditions, physical meaning, uncertainty, and whether evidence is prediction, numerical verification, or physical validation; a missed limit fails a result only if its origin is named. Write uses notebook results only after investigator promotion. A private scientific tool needs no compatibility, release, coverage, or API-hygiene work. Tests exist only for a numerical tolerance, invariant, or reference case. Name files, classes, tests, and terms only after a cited domain source or the quantity itself; obey BANNED.md in durable prose. A fix may pin its exact failing case once.
