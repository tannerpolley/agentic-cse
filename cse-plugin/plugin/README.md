# Agentic Computational Science and Engineering

The `cse` plugin supplies all 22 CSE skills under one namespace:
`cse:<skill>`. Source, data, visualization, and document rendering skills are
available together; their presence does not imply that Zotero, a corpus, or a
renderer is configured.

## Execution phases and review

1. Research and design: `setup`, `research`, `diagnose`, and `design`.
2. Execute and deliver: `build`, `analyze`, `summarize`, and authorized `write`
   and delivery work.

Independent `review` checks design readiness before execution and delivered
results or capabilities afterward. Supporting `prose` inspects scientific
writing and final manuscript cohesion; neither is an execution phase.

Direct execution is the default when no project preference or task override
exists. When baton mode is selected, the installed Baton Pass skill coordinates
roles and handoffs; CSE still owns its scientific stages and acceptance.

Use source skills for bounded Zotero, lineage, data, and digitization work.
Use rendering skills for retained values and selected document outputs. Missing
external capabilities must be reported specifically; plugin availability is
not a capability check.

The plugin uses source commits and installed payload hashes, not release
numbers. Its hook runtime remains a separate explicitly trusted installation.
