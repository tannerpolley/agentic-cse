# Mathpix transcription

Convert a confirmed Zotero PDF into a source-linked Markdown transcription with
Mathpix when no usable child exists.

Use only after the Zotero parent, PDF attachment, and missing usable source child
are confirmed and no usable Markdown companion exists. Return any consequential
equation, table, figure, or scan to the
owning core stage for applicability and Review's advice on claim support.

Run Companion's capability check and inspect every child. Preview conversion
with immutable input, destination, and authentication route. Mathpix is a paid
service; use native approval immediately before applying it. Compare equations, tables, figures,
headings, and OCR ambiguities with rendered source pages. Record parent and
attachment keys, content hash, format, and locators. The output is a
transcription, not validated scientific truth.

Respect the configured consent denylist. Attaching it to Zotero requires a
separate preview, approval, and verification. Values in a plotted figure go to `cse:digitize`.
