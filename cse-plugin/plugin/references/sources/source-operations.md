# Source operations

Source skills preserve exact source identity, locators, transformations, units,
basis, uncertainty, QA state, and limitations. They return evidence or a
bounded capability error to the invoking CSE stage.

Use the configured Zotero Companion and retained project records when source
authority or lineage is unresolved. The installed skill does not prove that
the Zotero executable, corpus, or authentication is available; check the
requested capability and report the exact missing prerequisite.
