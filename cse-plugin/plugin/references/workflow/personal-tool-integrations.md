# Optional personal tool integration

Read only when this plugin is installed. CSE remains usable without it.

## Matt Pocock's skills plugin

The installed plugin supplies optional engineering skills for software work.
CSE owns scientific questions, models, sources, data, numerical evidence,
notebooks, figures, and manuscripts. For overlapping skill names, choose by
subject:

| Subject | CSE | Engineering skill |
|---|---|---|
| Scientific sources or software investigation | `research` | `research` |
| Numerical disagreement or software bug | `diagnose` | `diagnosing-bugs` |
| Scientific support or code quality | `review` | `code-review` |
| Model and method or software specification | `design` | `to-spec`, `grill-with-docs` |
| Scientific calculation or software implementation | `build` | `implement`, `tdd` |

Project vocabulary uses the [CSE project glossary format](scientific-projects.md).
The Matt Pocock skills plugin owns its glossary maps and pre-1.3 `CONTEXT.md`
and `CONTEXT-MAP.md` files. CSE leaves their contents, relationships, and links intact.
For a detected pre-1.3 file, report only the plugin's upgrade step:
`git mv <path> <same dir>/GLOSSARY.md` (or `GLOSSARY-MAP.md`).

For a requested `/retro` session retrospective, use [CSE's science categories](retrospective.md)
alongside engineering findings. CSE supplies the categories, not a second
retrospective skill.
